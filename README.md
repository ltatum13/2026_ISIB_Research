**Changes in the Brain and Emotional Well-Being During Pregnancy**

Pregnancy is a time of rapid physiological change, but it can also be a time of heightened anxiety and emotional distress. The data we analyzed came from the Happy Brain Study, which used a non-invasive and practical brain imaging method known as functional near-infrared spectroscopy (fNIRS) to measure functional connectivity, or communication between different regions of the brain, during pregnancy. This project explored changes in functional connectivity across pregnancy as well as the correlation between changes in functional connectivity and changes in emotional well-being from the first to the third trimester. Our research also investigated whether baseline fNIRS connectivity could predict subsequent changes in symptom scores. We identified several significant changes in functional connectivity across pregnancy, with one prefrontal region emerging as a primary connectivity hub whose connectivity changes were associated with changes in distress symptoms.
